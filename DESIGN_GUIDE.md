# Jiangnan Tourism Poster Design Guide

## Project Overview
This repository contains Jiangnan (江南) cultural tourism poster designs featuring traditional Chinese water town aesthetics, suitable for marketing and public welfare campaigns.

---

## Design Philosophy

### Color Palette
| Color | Hex Code | Usage | Chinese Name |
|-------|----------|-------|------|
| Soft Blue | #8BADC7 | Water, sky, background | 水蓝 |
| Jade Green | #6B8E6D | Nature, plants, accent | 玉绿 |
| Muted Gray | #A9A9A9 | Shadows, depth | 灰色 |
| Off White | #F5F5F0 | Base, walls, contrast | 米白 |
| Deep Charcoal | #2C2C2C | Text, details | 炭黑 |

### Design Elements

#### Architecture
- Traditional wooden bridges (wooden railings, arched design)
- Black-trimmed whitewashed walls
- Tiled roofs (traditional glazed tiles)
- Pavilions with upturned eaves
- Waterside buildings and boat docks

#### Nature
- Willow trees (weeping branches)
- Lotus ponds and lotus flowers
- Misty mountains in background
- Flowing water (rivers and canals)
- Bamboo groves

#### Cultural Icons
- Oil-paper umbrellas (油纸伞)
- Traditional boats (小舟, 乌篷船)
- Qipao fashion (旗袍)
- Tea cups and tea culture
- Lanterns (traditional design)

#### Typography
- **Headlines**: FZYaoti, Noto Serif SC (elegant serif)
- **Calligraphy**: Hand-drawn style for accent text
- **Body Text**: Clean sans-serif for readability
- **Language**: Chinese characters with optional English subtitles

## Design Techniques

### Visual Effects
- **Ink Wash Blending**: Use opacity (20-30%) for watercolor effects
- **Layering**: Combine photography with vector illustrations
- **Depth of Field**: Blur backgrounds to emphasize foreground elements
- **Mist Effects**: Subtle gradient overlays for atmospheric perspective
- **Negative Space**: Maintain 30-40% empty space for elegance

### File Organization
```
/assets/
  /images/          # Photographs and base images
  /illustrations/   # Vector artwork
  /icons/          # Cultural icons and symbols
  /fonts/          # Font files (if custom)
  /color-swatches/ # Color palette files
  
/figma/            # Figma design files (exported)
  
/posters/          # Final poster designs
  /landscape/      # 1920x1080 format
  /portrait/       # 1080x1920 format
  /square/         # 1080x1080 format
  
/templates/        # Reusable Figma templates

```

## Export Specifications

### Digital (Web/Social)
- Format: PNG, JPEG, WebP
- Resolution: 72-150 DPI
- Color Space: RGB (sRGB)
- File Size: Optimize for web (<2MB)

### Print (Physical Posters)
- Format: PDF (high quality)
- Resolution: 300 DPI minimum
- Color Space: CMYK
- Bleed: Add 0.5" bleed margin

### Social Media Sizes
- Instagram Feed (1080x1350px)
- Instagram Stories (1080x1920px)
- Twitter Banner (1500x500px)
- Facebook Cover (820x312px)

## Design Workflow

1. **Research** → Study Jiangnan architecture, culture, existing posters
2. **Sketch** → Create wireframes in Figma
3. **Composition** → Arrange elements using design principles
4. **Color** → Apply palette and create visual hierarchy
5. **Typography** → Add text with proper hierarchy
6. **Effects** → Layer, blend, add atmospheric effects
7. **Refinement** → Review, adjust, fine-tune details
8. **Export** → Generate formats for different uses
9. **Testing** → Verify on different devices/print samples

---

## Accessibility Considerations

- Ensure sufficient color contrast (WCAG AA standard)
- Include text alternatives for visual elements
- Use clear, legible typography at various sizes
- Avoid color-only information (use patterns/icons)
- Test on various devices and screens
